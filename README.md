# Crypto-tracker-
Real-time cryptocurrency tracker with live prices, charts, and portfolio management.

✅ Main Features of CRYPTEX

1. Live Market Dashboard
Real-time crypto prices
Trending coins
Market overview (Market Cap, 24h Volume, BTC/ETH Dominance, Fear & Greed Index)
Price heatmap
Top Gainers & Top Losers
Searchable & sortable table

2. Portfolio Tracker
Add and track your holdings
Real-time total value, allocation, and Profit & Loss (P&L)

3. Built-in Tools
Converter – Crypto to fiat & vice versa
P&L Calculator
DCA Simulator
Position Sizer

4. Other Features
Multi-currency support (USD, PHP, EUR, etc.)
Dark/Light mode
Installable PWA (works like a mobile app)
Crypto news section
